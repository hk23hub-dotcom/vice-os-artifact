## Siglas del rubro (Chile)
| Término | Significado | Contexto |
|---|---|---|
| DOM | Dirección de Obras Municipales | permisos de edificación y recepción final |
| OGUC / LGUC | Ordenanza / Ley General de Urbanismo y Construcciones | normativa base |
| MINVU / SERVIU | Ministerio y Servicio de Vivienda y Urbanismo | subsidios, llamados, licitaciones |
| DS 1 / DS 19 / DS 49 | decretos de subsidio habitacional (clase media / integración social / Fondo Solidario) | ventas con subsidio |
| SEIA | Sistema de Evaluación de Impacto Ambiental | proyectos que requieren evaluación |
| ITO | Inspección Técnica de Obra | control de calidad y avance |
| EETT | Especificaciones técnicas | contratos y licitaciones |
| UF | Unidad de Fomento | precios, contratos, créditos |
| CChC | Cámara Chilena de la Construcción | índices, gremio |
| BCCh | Banco Central de Chile | tasas, inflación |
| EP / EDP | Estado de pago | facturación por avance |
| APU | Análisis de precios unitarios | presupuestos |
| GG | Gerente General (el agente, y el rol) | — |
