# Bitácora de sesiones

Un archivo por sesión: `YYYY-MM-DD.md` (si hay dos el mismo día, `YYYY-MM-DD-2.md`). Se escribe **durante** la sesión y se cierra al final.

```markdown
# Sesión YYYY-MM-DD

## Qué pedía Diego
- …

## Qué se hizo
- …

## Decisiones (copiadas también a decisiones.md)
- …

## Pendientes nuevos o movidos (copiados también a pendientes.md)
- T-#### …

## Preguntas que quedaron abiertas
- …

## Para recordarle la próxima vez
- …
```
