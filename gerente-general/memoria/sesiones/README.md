# Bitácora de sesiones

Un archivo por sesión: `YYYY-MM-DD.md`. Se escribe **durante** la sesión y se cierra al final. Si el mismo día hay otra
sesión, se anexa al mismo archivo un bloque `---` + `_Bloque HH:MM_` repitiendo las mismas secciones `##` (no se
sobrescribe); `YYYY-MM-DD-2.md` solo si el gerente lo pide. Las bitácoras de subagentes van en `YYYY-MM-DD-<área>.md`.

```markdown
# Sesión YYYY-MM-DD

## Qué pedía Diego
- …

## Qué se hizo
- …

## Decisiones (copiadas también a decisiones.md)
- …

## Pendientes nuevos o movidos (copiados también a pendientes.md)
- T-#### …

## Preguntas que quedaron abiertas
- …

## Para recordarle la próxima vez
- …
```
