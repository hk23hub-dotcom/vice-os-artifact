# Radar — fuentes de partida (Chile, construcción y vivienda)

Cada entrada del radar lleva URL y fecha de consulta. Si una fuente no responde, se dice; no se rellena de memoria.

## Normas, permisos, subsidios
| Tema | Dónde mirar | Qué buscar |
|---|---|---|
| Subsidios habitacionales (DS 1, DS 19, DS 49, arriendo) | minvu.gob.cl · serviu regional | llamados abiertos, fechas, montos, requisitos para empresas constructoras / inmobiliarias |
| Normativa urbanística (OGUC, LGUC) y circulares DDU | minvu.gob.cl/ddu | cambios que afecten permisos, densidad, estacionamientos, eficiencia energética |
| Permisos de edificación y recepción | DOM de la comuna | plazos, requisitos, cambios de plan regulador |
| Evaluación ambiental | sea.gob.cl | si un proyecto debe ingresar al SEIA |
| Leyes nuevas (copropiedad, integración social, eficiencia energética) | bcn.cl/leychile · diariooficial.interior.gob.cl | publicación, vigencia, reglamento |
| Licitaciones públicas | mercadopublico.cl · SERVIU · municipios | obras, montos, fechas de cierre |
