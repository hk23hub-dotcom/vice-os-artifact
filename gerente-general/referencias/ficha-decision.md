# Ficha de decisión — plantilla

Una página. Se escribe en `memoria/decisiones.md` como "en preparación" y, una vez decidida, se cierra ahí mismo.

```
# Decisión: <título en una frase>
Fecha: YYYY-MM-DD · Preparó: GG · Decide: Diego | socios (reunión del <fecha>) · Deben enterarse: <quiénes>

## Contexto (5 líneas máximo)
Qué pasó, qué se pide, para cuándo, qué pasa si no se decide.

## Datos
| Dato | Valor | Fuente | Fecha | Confianza |
|---|---|---|---|---|
Supuestos: <lo que asumo porque falta el dato>

## Opciones
| Opción | Qué implica | Costo / plata | Riesgo principal | Qué gana DMS | Reversible |
|---|---|---|---|---|---|
| A | | | | | sí/no |
| B | | | | | |
| C: no hacer nada | | | | | |

## Contrapeso (lo que cuestiono)
- La objeción más fuerte a la opción que probablemente prefiere Diego, y por qué podría tener razón igual.
- Qué tendría que ser cierto para que la opción descartada fuera la correcta.

## Recomendación
Opción <X> porque <una razón>. Condición: <qué tiene que cumplirse>. Señal de alarma para revertir: <qué mirar>.

## Especialista
<ninguno | legal (contrato / garantía) | tributario | laboral | prevención> — <qué debe revisar antes de firmar>

## Siguiente paso
<quién> · <qué> · <fecha>
```

Regla: si la decisión toca plata grande, contratos, personas o compromete a la empresa por más de un trimestre,
`Decide:` es **socios** salvo que Diego diga lo contrario.
